# Qwen3-4B 微调实验协议

日期：2026-09-11。状态：进行中，尚无微调效果结论。

目标是实际训练模型、改善 CoursePilot 可信问答，并产生可用于简历的可复现对照结果。不能用模板训练集上的分数、降低评测门槛或仅降低 loss 代替最终效果。

## 环境与范围

- 用户授权的服务器实验目录：`/home/ccnu/Code/LXP/coursepilot-qwen3-sft`（Linux 路径区分大小写）。
- 容器可见两张 RTX 4090 D，各 24GB；先用单卡，运行前检查空闲情况。内存配额约 8GB，需要低内存加载。

- 原模型：`Qwen/Qwen3-4B`，Apache-2.0，锁定模型 revision。
- QLoRA：4-bit NF4、double quantization、BF16 计算、LoRA 适配器；仅训练适配器，记录可训练参数量。
- 原模型和适配器对比使用同一推理精度、硬件、提示词、解码配置与 Token 预算；不同部署后端单列实验。

## 数据与实验

1. 先修复引用评测忽略不匹配引用的问题，按每个生成 Claim–Citation 配对统计，错误引用不能增加覆盖率。保留历史报告，新口径单独标版本。
2. 为无可回答证据定义合法 `{"claims": []}`，核心流程返回已有拒答状态；该机制同时用于原模型和微调模型，单独记录工程改动，避免把工程改动收益全归因于微调。
3. 原创课程风格行为数据按资料/概念分组划分 train/dev/test。包含有依据回答、多个证据、干扰资料、否定与条件、错误预设和资料不足。明确标为 AI 辅助构造，不声称人工教师盲标。
4. 已有 360 条内部冻结用例不用于训练；外部公开数据若引入，固定来源、许可证和选择规则。测试问题与答案不用于 checkpoint 选择。
5. 先冻结数据文件与 SHA256，再运行原模型基线和训练；只用开发集选模型。最终测试如暴露问题，要保留结果，新增开发数据后使用新的未调参测试版本确认。
6. 同时记录原始模型输出与经过 Agent 防护后的输出，避免摘要降级掩盖模型生成失败。

## 指标及验收证据

- 原始输出：JSON/Schema 成功率、引用编号合法率、全部输出引用的来源支持代理指标、答案覆盖/文本匹配、不可回答拒答率与可回答误拒答率；逐项保留分子分母。
- 系统效果：真实 TrustedAgentCore 调用的回答、拒答、摘要降级、生成次数、延迟分布；另行运行实际检索 QA 回归，不以给定证据实验替代全链路。
- 延迟：预热后相同输入、相同输出预算；报告 P50/P95、输出 Token、生成速度、峰值 GPU 显存。单并发不能包装成高并发。
- 训练：数据哈希、Git 提交、基础模型 revision、LoRA 配置、优化器、学习率、批次、梯度累计、长度、seed、loss、耗时、依赖版本、checkpoint 文件哈希。
- 必须实际生成可加载的适配器，并验证其接入 CoursePilot 的模型适配器；对生成失败或拒答的行为保留回归测试。
- 最终材料：训练与推理脚本、数据构造与划分说明、原始基线/微调报告、改进和退化案例、简历事实版本及面试取舍说明。

不预填任何提升数字。引用词法匹配只能称代理评测，不称严格语义蕴含。若没有观察到可靠增益，报告负结果并继续在开发集定位，不调整测试标签迎合模型。
