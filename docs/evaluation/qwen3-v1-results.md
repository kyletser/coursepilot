# Qwen3-4B QLoRA v1：结果与发布判断

2026-09-11。已实际训练、保存适配器、重新加载并通过真实 CoursePilot 模型适配器调用。
**本版不替换默认模型**：合成行为测试明显改善，但原课程全链路多出一次误拒答。

## 实验设计

- 原模型：Qwen/Qwen3-4B，revision `1cfa9a7208912126459214e8b04321603b3df60c`。
- RTX 4090 D 单卡；NF4 四位量化、double quantization、BF16 计算。
- LoRA r=16、alpha=32、dropout=0.05、all-linear；仅训练 33,030,144 个参数，约占含适配器总参数的 0.81%。不是四位权重全参数训练。
- 688 train / 100 dev / 172 test；原创 AI 辅助构造，按课程概念及模拟机器标识隔离。不是教师盲标数据，不是线上学生提问。
- 只对 assistant 输出计算 loss；prompt 标签为 -100；batch=1、梯度累计=8，学习率 1e-4，2 epochs，seed=20260911。
- 梯度检查点、paged AdamW 8-bit；显式 labels 和 prediction-loss-only，避免 PEFT 标签识别问题及保留整张词表 logits。
- 最低 dev loss 选择 checkpoint-86（第一轮）；两轮 dev loss 为 0.00553608、0.00562742。没有用 test 选 checkpoint。
- 训练约 497 秒，峰值已分配显存 5.79 GB（十进制）；这不是整卡保留显存，也不是推理常驻显存。

## 给定证据的独立留出测试

两个模型使用相同提示词、量化配置、硬件、贪心解码、384 输出 Token 上限；
真实 TrustedAgentCore 同时保留防护前后的结果。该实验不计检索召回。

| 指标 | 原模型 | 微调模型 |
|---|---:|---:|
| JSON Schema 有效 | 172/172 | 172/172 |
| 预定义词法任务成功代理 | 127/172 | 170/172 |
| 完全匹配参考 claims | 75/172 | 170/172 |
| 不可回答拒答 | 30/40 | 40/40 |
| 可回答误拒答 | 0/132 | 2/132 |
| 生成 P95 | 1.272 s | 2.179 s |

同一用例配对：44 条改善、1 条退化、127 条判定不变。按 42 个来源组做
10,000 次 cluster bootstrap，代理成功率差值 +25.0 个百分点，95% percentile
区间约 [+17.5, +35.8] 个百分点。该区间只反映此合成分布的不确定性，不能解决
模板相似或标注不独立的问题，不能外推为真实问答准确率。

词法任务成功要求标签集合匹配、所有输出 Claim–Citation 配对通过 gold 文本
char-F1≥0.7，并满足整体文本匹配；负例要求合法空 claims。这会奖励抽取式输出，
可能误伤正确转述，也不能排除高重叠但语义错误的答案。因此不用“准确率 98.8%”
或“幻觉率下降 25%”描述这个结果。

两条微调误拒答均为写时复制提问的不同措辞；保留原始输出，不修改 gold。
未合并 LoRA 推理更慢，不能把减少输出 Token 描述成推理加速。

## 原课程全链路回归

使用真实 PostgreSQL/pgvector、BGE-M3、BM25、RRF、BGE Reranker、版本校验和
TrustedAgentCore，经过现有 OpenAI-compatible Adapter 调用远程模型。
两门课各 40 条原冻结 QA，共 80 条；这些历史课程用例是回归集，不称新外部盲测。
原库复制到独立 `coursepilot_sft_eval` 数据库，原库未覆盖。两课程交替模型先后顺序。

| 指标 | 原模型 | 微调模型 |
|---|---:|---:|
| 不可回答拒答 | 40/40 | 40/40 |
| 可回答误拒答 | 3/40 | 4/40 |
| 参考 claim 词法对齐配对 | 8/53 | 8/37 |
| 完整请求 P95 | 4.168 s | 4.053 s |

P95 小幅差异只有一次运行，不能声称稳定加速。原报告字段 `citation_accuracy`
在本版事实上是**参考 claim 对齐代理**：一些正确引用原文的转述或补充事实，
因为 gold 没包含相关部分而判负。不能把低值解释成大量幻觉，也不能把更少的
输出配对造成的比率上升当成质量提升。

新出现的误拒答是“链表插入常数时间所需前提”。基线回答了“已经定位到相邻节点”，
微调模型拒答。该事实说明仅凭短证据合成测试发布模型是不够的。

## 下一轮原则

1. 不修改既有测试标签，不删除失败案例，不将 v1 的测试继续称为未见测试。
2. 在 train/dev 内增加长段落、多事实、条件句及真实转述，不只增加问题前缀。
3. 保留短证据拒答收益，但单独设置可回答误拒答门槛；新增未用于调参的测试材料。
4. 使用外部公开阅读理解数据作补充，固定选择规则、许可和来源哈希；明确与课程回归的区别。
5. 只有新证据支持收益且课程回归不过度退化，才讨论默认模型切换。

## 现在能用于简历的事实

> 面向课程资料不足时仍生成结论的问题，使用 QLoRA 对 Qwen3-4B 做证据约束 SFT，

> 误拒答退化，保留发布门槛与原模型回退方案。
