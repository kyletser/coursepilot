但查看全部 19 条 QLoRA 配对改善，发现大部分原模型转述也正确，只是不逐字摘录。

## 6. 系统优化与方案选择

本轮对当前 Agent 的确定性改进，不依赖采用哪个模型：

1. 支持合法空 `claims` 表达模型拒答，直接返回已有 INSUFFICIENT_EVIDENCE，
   不再把主动拒答当成解析失败并改为无关证据摘要。
2. 引用评测按全部生成 Claim–Citation 配对计数，错误/未知引用不能从分母消失，
   也不能因为来源 ID 正确就给无关结论加分。
3. 保存生成前、重试与防护后输出，模型效果、系统降级和运行错误分开统计。
4. 模型接口、课程权限、版本隔离和学习状态事务边界不变。

RAG 与微调负责不同问题：检索提供可更新的课程事实；微调适配输出与拒答行为。
现有 200 条课程检索实验中 Hybrid/Reranker 相对 Dense-only 的结果仍见原检索
报告，不能与本轮新模型测试合并成一个提升率。默认保留本地 Ollama，实验服务
通过 SSH 隧道只监听 loopback；不把串行验证端点当作生产推理平台。
